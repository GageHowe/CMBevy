Gametype Reference

Gametype scripts are Lua files under assets/gametypes.

Runtime features

Feature Meaning
Lua source file Gametypes are plain Lua scripts loaded from assets/gametypes or sent over the network.
Shared client/server execution The same script runs on both sides. Use IS_SERVER to guard authority-only behavior.
Hook-based execution Specific function names are called by Rust when present.
ModeConfig globals Specific top-level globals are read once to populate authoritative mode metadata.
Script API globals Rust registers a fixed set of callable Lua functions for world queries and round control.

Hook functions

Hook Arguments Meaning
on_tick none Called during Bevy Update.
on_fixed_tick none Called during Bevy FixedUpdate.
on_player_killed (victim, killer) Called after authoritative death handling. killer may be nil.

Built-in runtime globals

Name Meaning
IS_SERVER Boolean indicating whether the script is currently executing on the authoritative server.
FIXED_TICK_RATE Fixed simulation rate.
FIXED_DELTA_SECONDS Seconds per fixed tick.

ModeConfig globals

Name Meaning
RESPAWN_DELAY Player respawn delay in seconds.
TEAMS_ENABLED Whether the mode uses teams.
SCORING "unscored" or "score_to_win".
SCORE_TO_WIN Target score when using score_to_win.
TIME_LIMIT_SECS Round length in seconds.
LEADERBOARD_SCOPE "none", "team", or "player".
LEADERBOARD_NUMBER_INDEX Which counter the HUD should show.
TEAM_COUNT Team count for team modes.
LEADERBOARD_LABEL HUD label for the main score number.
PRIMARY_OBJECTIVE_LABEL Short objective text.

Script API functions

Function Meaning
get_tagged(tag) Returns all entities matching a script tag.
get_first_tagged(tag) Returns the first entity matching a script tag.
entity_has_tag(entity, tag) Tests whether a specific entity has a specific script tag.
entity_exists(entity) Tests whether an entity id still exists.
get_entities_in_zone(entity) Returns entities currently inside a ScriptZone entity.
is_player(entity), is_bot(entity) Entity classification.
get_players() Returns all player character entities.
get_match_phase(), get_match_phase_time() Reads the current round phase and elapsed time in that phase.
end_game(), end_game_with_player_winner, end_game_with_team_winner, restart_round() Round flow control.
show_message(text) Pushes a message to players.
get_player_number, add_player_number Per-player scoring or objective counters.
get_team_number, add_team_number Per-team counters.
get_health(entity), entity_alive(entity), set_health(entity, amount) Read or write health values for an entity.
spawn_pawn(team, kind) Server-only pawn spawn helper. Current accepted kinds are limited.
add_bot(entity, brain) Turns an existing pawn entity into a bot. Currently only the killer brain is accepted.
spawn_bot(team, brain) Convenience helper for spawning and bot-enabling a biped.
give_weapon(entity, kind) Server-only weapon grant.
despawn(entity) Despawns an entity by id.

Conventions

  • Mode scripts define only script-level conventions. Names like hill or number-index layouts are not built-in engine contracts.
  • Server-authoritative state changes should be guarded with IS_SERVER.
  • Map integration is usually done with ScriptTags and ScriptZone rather than hard-coded entity ids.
