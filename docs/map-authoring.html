Map Reference

Maps are Bevy dynamic scenes written as .ron files under assets/maps.

Scene format

Key Meaning
resources Map-wide resources keyed by reflected type name.
entities Entity id map. Each entity contains a components table.
components Reflected component values keyed by short type name.

Short type names are expanded by the level preprocessor before deserialization.

Transform.rotation also accepts from_euler((x, y, z)), interpreted as XYZ Euler angles in degrees and rewritten to a quaternion during preprocessing.

Resources

Type Fields Meaning
MapMeta visuals, skybox, skybox_brightness, env_light_intensity, ambient_light_color, ambient_light_brightness Level-wide visual and lighting metadata.

Core scene components

Type Fields Meaning
Transform translation, rotation, scale Local transform for authored entities.
ChildOf Parent entity id Scene hierarchy parent relation.
StaticCollider shape, scale Fixed collider authored in the scene. World pose comes from Transform.
ColliderMaterial friction, restitution Surface material for scene-authored colliders.
SceneModel path Client-only GLB scene path attached to an entity.
SpawnPoint team Player or bot spawn location.
Spawner kind, respawn_delay_secs Respawning world object spawner for weapons, vehicles, pickups, or pawns.
ScriptTags tags String tags visible to gametype scripts.
ScriptZone shape Script-visible query volume evaluated in world space.

Physics and motion types

Type Fields or variants Meaning
Shape Authoring shape enum Collider or query volume shape used by StaticCollider and ScriptZone.
SceneRigidBody Fixed, Dynamic, Kinematic Rigid body mode for scene-authored physics bodies.
InitialVelocity (Vec3) Initial linear velocity for scene-authored bodies.
InitialAngularVelocity (Vec3) Initial angular velocity for scene-authored bodies.

Gameplay-oriented map types

Type Fields or variants Meaning
GravityProfile InverseSquare(f32), Linear(f32), Constant(f32) Strength curve for gravity authored by a GravitySource.
GravityKind Point, Axis(Vec3) Planet-style center pull or ring-style axis behavior.
GravitySource kind, inner_radius, radius, half_width, profile Authored gravity volume.
SnapKind Point, Axis(Vec3) How biped up-direction is chosen.
SnapSource kind, inner_radius, radius, half_width Authored orientation source for bipeds.
ZoneEffectKind Safe, OutOfBounds Zone effect behavior.
ZoneEffectRegion Inside, Outside Whether the effect applies inside or outside the zone shape.
ZoneEffect kind, region, priority, countdown_secs, damage_fraction_per_sec Zone-driven safe or harmful gameplay effect.
CollisionFxMaterial Dust, Sparks Client-side impact effect material for collision reactions.

Client-only presentation types

Type Fields Meaning
AreaReverbComponent min_distance, max_distance Client audio reverb zone.
PlanetAtmosphere planet_radius, shell_thickness, color, density, opacity, sun_intensity, forward_scatter, specular Client-rendered atmosphere shell around a planet-like body.
DirectionalLight Bevy light fields Authorable scene lighting.
CascadeShadowConfig Bevy shadow cascade fields Directional light cascade tuning.

Conventions

  • Short names such as MapMeta and ScriptZone are loader conveniences, not engine-native type paths.
  • Map and gametype agreements such as a tag named hill are conventions, not built-in contracts.
  • Child transforms and parent rigid bodies affect world-space spawning and zone evaluation.
