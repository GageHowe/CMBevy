Convention: tag-driven zone lookup

A mode can decide that a map entity tagged hill is the scoring zone.

"ScriptZone": (
  shape: Ball(180.0),
),
"ScriptTags": (
  tags: ["hill"],
),

The engine does not reserve the tag name hill. The map and mode agree on it by convention.

Conventions

  • Prefer string tags and query zones for map-to-mode integration.
  • Use ChildOf when objects should inherit parent motion and authored local space.
  • When a parent body moves or spins, downstream spawning and zone world pose will follow that parent.
