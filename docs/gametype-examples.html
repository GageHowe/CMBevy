Gametype Examples, Conventions, and Snippets

Examples taken from current scripts. They demonstrate patterns, not engine-mandated contracts.

Minimal scoring mode

RESPAWN_DELAY = 5.0
TEAMS_ENABLED = false
SCORING = "score_to_win"
LEADERBOARD_SCOPE = "player"
LEADERBOARD_NUMBER_INDEX = 0
SCORE_TO_WIN = 25
TIME_LIMIT_SECS = 600.0
TEAM_COUNT = 2
LEADERBOARD_LABEL = "Kills"
PRIMARY_OBJECTIVE_LABEL = "Eliminate enemies"

function on_player_killed(victim, killer)
    if not IS_SERVER then
        return
    end
    if killer == nil or killer == victim then
        return
    end
    add_player_number(killer, 0, 1)
    if get_player_number(killer, 0) >= SCORE_TO_WIN then
        end_game_with_player_winner(killer)
    end
end

Convention: map tag lookup

local hill = get_first_tagged("hill")
if hill == nil then
    return
end

for _, entity in ipairs(get_entities_in_zone(hill)) do
    if is_player(entity) then
        add_player_number(entity, PLAYER_NUMBER.score, 1)
    end
end

This works only if the map author chooses the same hill convention.

Snippet: bot spawning

local bot = spawn_bot(0, "killer")
if bot ~= nil then
    give_weapon(bot, "beamer")
end

Conventions

  • Guard authoritative state changes with IS_SERVER.
  • Use top-level config globals for round metadata and HUD labels.
  • Use tags and zones to bind a mode to map-authored areas.
  • Document any custom tag names, counter indices, or expected zone layouts next to the script.
